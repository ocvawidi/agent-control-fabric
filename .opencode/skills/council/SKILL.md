# ACF Council Skill

Use this skill for architecture, high-uncertainty research, high-impact technical decisions, or requests that explicitly ask for a second opinion.

## Flow

1. Frame the decision and constraints.
2. Select the smallest useful council.
3. Give each advisor a non-overlapping lens.
4. Collect outputs without unnecessary anchoring.
5. Ask a reviewer to identify contradictions, unsupported claims, and missing assumptions.
6. Synthesize consensus, dissent, evidence gaps, and the next test/action.

Consensus is not proof. A single-model council is not independent model consensus.
