# Writing quality

Use for user-facing writing, docs, reports, messages, proposals, and similar prose.

Rules:
- preserve meaning and voice;
- prefer the minimum effective edit;
- remove generic AI patterns only when they add no value;
- prefer concrete claims to vague importance language;
- do not invent attribution, examples, numbers, or quotes;
- provide a detect-only mode when the user asks for an audit.
