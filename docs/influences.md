# Conceptual influences

This project is an original implementation. The following public projects informed the design vocabulary and patterns; their source files are not copied into ACF.

- Ponytail — https://github.com/dietrichgebert/ponytail
- LLM Council Skill — https://github.com/gcpdev/llm-council-skill
- Claude Skills LLM Council — https://github.com/aiwithremy/claude-skills-llm-council
- Academic Research Skills — https://github.com/Imbad0202/academic-research-skills
- Anti Slop — https://github.com/miqdadbadjuber/anti-slop
- No AI Slop — https://github.com/petergyang/no-ai-slop
- OpenCode Agents — https://opencode.ai/docs/agents
- OpenCode Skills — https://opencode.ai/docs/skills

The project intentionally generalizes concepts rather than importing domain-specific prompt text. Check each upstream repository's current license and notices before copying any material.
