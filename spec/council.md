# Council contract

Council is an escalation mechanism, not the default execution mode.

A council run should:

1. frame the question before dispatch;
2. assign non-overlapping roles;
3. collect independent-looking candidate analyses;
4. review candidates without unnecessary anchoring;
5. surface dissent and unresolved assumptions;
6. verify claims that can be checked externally;
7. synthesize without treating consensus as truth.

Single-model council is considered perspective diversity, not model independence.
